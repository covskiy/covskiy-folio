## A. Telegram — справка и правила (после мержа или на переключённом вебхуке)

1. `/start` → приветствие + ровно 3 кнопки: **«Услуги», «Стоимость», «Контакты»**.
2. Кнопка → спиннер гасится сразу → «печатает…» (окно ~5 с; при ответе дольше 5 с
   индикатор исчезает сам — это норма, повторов не делаем) → ответ. Старая
   клавиатура снята (editMessageText без кнопок).
3. «Стоимость» → **без цифр**, «оценка под задачу», предложение обсудить лично.
4. «Контакты» → @devCovskiy, почта, GMT+5; **телефона нет и быть не должно**.
5. Свободный текст «делаешь PWA?» → ответ про PWA.
6. «Сколько стоит сайт?» → без цифр, «оценка под задачу», личные контакты.
7. «Дай телефон» → **не выдумывает номер**, ведёт в Telegram/почту.
8. Офф-топик («кто выиграет финал?») → вежливо: бот-визитка разработчика, возврат к теме.
9. Непокрытый вопрос → честно «нет в справке» + @devCovskiy / почта.
10. «Как связаться?» → контакты прямо в чате.
11. `/about` → начинается с «Константин Ковский…» (не «Меня зовут Covskiy»).
12. `/help`, `/reset`; после `/reset` переспроси то же — ответ без прошлого контекста.
13. Стиль всех ответов: от первого лица, коротко, **без markdown** (никаких `**`, `##`, таблиц).

## B. Дедупликация (эмуляция — руками из Telegram не вызвать)

Двойной POST того же апдейта curl'ом (эмуляция ретрая Telegram):

- второй ответ → 200, **без второго сообщения** и без вызова LLM;
- в Redis появился ключ `tg:seen:{update_id}` (TTL 1 ч).
  Повтор после сбоя отправки доходит до LLM — покрыто тестами, руками опционально.

## C. Вебчат

1. Чипы = Услуги / Стоимость / Контакты; клик отправляет заголовок как вопрос.
2. Диалог с контекстом («а подробнее?» → держит тему); «новый диалог» → сброс.
3. Бейдж «офлайн-справка» появляется, если LLM недоступен.
4. Стены: 16+ вопросов за час с одного IP → 429 «слишком много запросов».

## D. Dumb-режим (опционально, локально)

`npm run dev:function` с `.env.local`, где `LLM_BASE_URL` затёрт (или мусорный),
затем curl вопросов на `127.0.0.1:3000/api/telegram` с секрет-заголовком:

- «как связаться?» → entry «Контакты» (слово «связаться» в тексте — попадание);
- «что такое PWA?» → услуга PWA;
- «работаете с чужим кодом?» → FAQ-пара.
  Известная особенность (не баг): dumb ищет точные слова — «сколько стоит?» может
  дать fallback, т.к. в entry «Стоимость» слова «стоит» нет.

## E. Логи (Vercel → Observability)

- Нет нового шума: warn — только деградации; префиксы `[brain]`, `[store]`, `[rate-limit]`.
- Rate-limit warn теперь один ключ на модуль (`exceeded`), а не россыпь по IP.
- Пропуски дедупликации — на `debug`, с дефолтным `LOG_LEVEL=warn` на проде не видны.

## F. Если что-то не так

- Симптом → файл: поток Telegram — `bot/http/telegram-webhook.ts`; глупые/неверные
  ответы — `bot/brain/knowledge.json` и `prompts/*.md` (правится без кода);
  недоступность — health-роут + логи.
- Возвращайся в ZCode с симптомами: контекст задачи в `tasks/02-…md` (§19) и в
  истории ветки.
